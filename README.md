# 🍽️ Efood

Uma aplicação web de delivery de restaurantes desenvolvida com **React e TypeScript**, permitindo que o usuário navegue pelos restaurantes, visualize os pratos disponíveis e realize um pedido através de uma interface moderna e responsiva.

O projeto foi desenvolvido como parte da formação em **Engenharia Front-end da EBAC**, com foco na aplicação prática de conceitos de React, gerenciamento de estado, roteamento e componentização.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/PriscilaDurao/efood.git
```

### 2. Acesse a pasta do projeto

```bash
cd efood
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm start
```

A aplicação será iniciada no ambiente de desenvolvimento e poderá ser acessada pelo navegador.

## 📦 Build

Para gerar a versão de produção:

```bash
npm run build
```

O projeto utiliza os scripts do Create React App para iniciar a aplicação, executar testes e gerar o build de produção.

## 🎯 Objetivo do projeto

O objetivo deste projeto foi desenvolver uma aplicação de delivery colocando em prática conceitos importantes do desenvolvimento Front-end moderno, como:

* Desenvolvimento de interfaces com React
* Tipagem com TypeScript
* Componentização
* Gerenciamento global de estado com Redux Toolkit
* Navegação entre páginas com React Router
* Criação de interfaces estilizadas com Styled-components
* Manipulação de dados e estados da aplicação
* Criação de uma experiência responsiva
* Organização e reutilização de componentes
